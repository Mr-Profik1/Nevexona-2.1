NEVEXONA2.1 GAMING · DEV

Лёгкая система на базе Debian 13 (Trixie), 64-бит. Проект в ранней разработке: образ собирается автоматически, но проверен не на всех компьютерах.

Скачать ISO

Рядом с файлом лежит SHA256 для проверки. Если релизов пока нет, образ ещё не опубликован.

Загрузочная флешка с телефона (EtchDroid)

  1. Скачайте ISO на телефон по кнопке выше.
  2. Подключите флешку к телефону через OTG-переходник.
  3. Откройте EtchDroid → Write raw image (запись образа) → выберите ISO → выберите флешку.
  4. Дождитесь окончания записи. Все данные на флешке будут стёрты.
  5. Вставьте флешку в ПК, включите его и выберите загрузку с USB (обычно F12, F11, Esc или Del).

С компьютера

Windows: Rufus в режиме «DD-образ». Любая ОС: balenaEtcher.

Важно

Сначала проверьте систему в режиме Live, не устанавливая её на диск. Установщик на жёсткий диск ещё в разработке. Совместимость с каждым компьютером и играми не гарантируется.
